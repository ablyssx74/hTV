# Haiku SDL2 Audio/Video Player with nebula opengl support.

1. The only Haiku Video/Audio player that supports multi-threaded LLVM processes.  
2. The only Haiku Video/Audio player that auto detects if the user has Nebula Nvidia driver installed.
3. The only Haiku Video/Audio player that uses hardware accelerated playback for the Nebula driver.

Supports 64/32 bit builds

### To build
```
make release
```
